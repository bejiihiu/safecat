# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in SafeCat, please report it privately by emailing **bejiihiu.xs@gmail.com** (or whatever address the maintainer uses). Do **not** open a public GitHub issue.

You can also use GitHub's private vulnerability reporting mechanism if the repository has it enabled.

We aim to respond within **72 hours** and publish a fix within **14 days** of confirmation, depending on severity.

## Scope

In-scope: the SafeCat codebase (api, common, forge, fabric, neoforge modules).

Out-of-scope: Minecraft itself, loaders (Forge/Fabric/NeoForge), or any third-party provider mods.
